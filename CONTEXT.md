# AGAP

AGAP is an emergency alert and response platform. Citizens raise alerts and file Reports from a mobile app, and responders act on them from a web dashboard.

## Language

**Citizen note**:
The chips and free text a citizen adds to a Report in their own words, kept separate from the photo description.
_Avoid_: user note, reporter note, extra details

**Photo description**:
The text written automatically by AI from a Report's photo. It can be wrong, so it is always labelled as AI-written to responders.
_Avoid_: description (on its own), AI analysis, summary

**Body side**:
Left or right as the injured person's own left and right, never as it appears in a photo. It can be unknown when a photo doesn't show it, and is then stated as unknown rather than guessed.
_Avoid_: image left, photo right, viewer's left
